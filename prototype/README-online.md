# 줄 위의 극장 — 온라인 플레이

친구들과 같은 방에서 최대 4명이 함께 합니다. 빈 자리는 봇이 채웁니다.
게임 계산은 **방장의 브라우저**가 하고, 서버(`server.js`)는 방 관리와 메시지 중계만 합니다.

## 실행
1. Node.js 18 이상을 설치합니다. (추가 패키지 설치 없음)
2. 이 폴더에서 서버를 켭니다.
   ```
   node server.js            # 기본 포트 8080
   PORT=3000 node server.js  # 포트 변경
   ```
3. 서버를 켠 사람(또는 아무나)이 `http://서버주소:8080` 으로 접속합니다. 서버가 게임 파일(`assembly.html`)도 같이 내려 주므로 친구들도 같은 주소로 들어오면 됩니다.
   - 같은 와이파이: 서버를 켤 때 출력되는 `http://192.168.x.x:8080` 주소를 알려 주세요.
   - 인터넷 너머 친구: 공유기에서 포트(8080)를 열거나, `cloudflared tunnel --url http://localhost:8080` / `ngrok http 8080` 같은 터널을 쓰면 됩니다. 터널을 쓰면 주소가 https 로 나오며, 게임이 자동으로 `wss://` 로 연결합니다.
4. 타이틀 화면에서 **온라인 (친구와)** → 방장은 **방 만들기**, 친구들은 방장이 알려 준 4글자 **방 코드**를 넣고 **코드로 참가**. 모이면 방장이 **게임 시작**.

`assembly.html` 파일을 그냥 더블클릭해서 연 경우에는 서버 주소 칸에 `ws://서버주소:8080/ws` 를 직접 적어야 합니다.

## 알아 둘 점
- 방장이 창을 닫거나 탭을 백그라운드로 보내면 게임이 멈추거나 끝납니다. 방장은 게임 창을 앞에 두세요.
- 중간에 나간 참가자는 봇으로 바뀌어 게임이 계속됩니다. 재접속은 지원하지 않습니다.
- 한 명이 오래 응답하지 않으면 정해진 시간 뒤 자동으로 넘어갑니다(실 선택은 15초).
- 탐색은 약 15회/초, 듀얼은 약 15회/초로 상태를 받아 그립니다. 평소 인터넷 환경에서 클라이언트당 20~250KB/s 정도입니다.
- 테스트용 주소 파라미터: `?online=host&nick=이름&need=2` (방 만들고 2명 모이면 자동 시작), `?online=join&room=ABCD&nick=이름`, `&server=ws://주소/ws`.
