# 보스전 모드 설계안 (다대1 비대칭)

## 한 줄 요약
게임 시작 때 한 명이 **보스**로 정해지고, 나머지는 **영웅 팀**이다. 매 소집마다 **탐색(3분) → 보스전(여러 턴)**을 돌리고, 보스의 체력이 0이 되면 영웅 승, 영웅이 전원 쓰러지거나 소집 한도가 차면 보스 승이다.

## 1. 게임 흐름

```
시작: 보스 1명 추첨 (온라인이면 방 인원 중 랜덤, 봇 포함) · 영웅은 직업 랜덤 배정
 └ 소집 1..5 반복
     1) 탐색 3분  ── 영웅: 지금의 탐색 (상자·발전기·괴물)   /  보스: 보스 아바타로 영웅 사냥
     2) 보스전    ── 정해진 영역에서 N턴 (패턴 구간 ↔ 공격 구간)
     3) 정산      ── 재화로 영웅 강화, 쓰러진 영웅 부활 준비
 └ 영웅 승: 보스 체력 0   /   보스 승: 영웅 전원 동시에 쓰러짐 또는 5소집 후에도 보스가 살아 있음
```

## 2. 보스전 (핵심)

### 턴 구조 (한 소집에 3~4턴)
| 구간 | 길이 | 영웅 | 보스 |
|---|---|---|---|
| **패턴 구간** | 약 10초 | 이동해서 탄막을 피한다 (평타는 계속 나감) | 패턴 1~2개를 발동. 패턴마다 쿨타임 |
| **공격 구간** | 약 6초 | 직업 스펠로 보스를 집중 공격 | 느리게 움직이며 약한 평타만 (경직) |

- 영웅은 **하트 3칸**(재화로 최대 5칸). 맞으면 1칸, 0이 되면 쓰러져 **구경**한다.
- 쓰러진 영웅은 **다음 소집 시작 때 하트 1칸으로 부활**한다 (수선공이 일으키면 2칸).
- 전원이 같은 소집에서 쓰러지면 보스 승으로 즉시 종료.

### 보스 체력과 인원 보정
- 보스 체력 = 영웅 수 × 기본값 × (소집 보정). 영웅이 적으면 체력도 낮아진다.
- 체력 50% 이하에서 **분노**: 새 패턴 해금 + 쿨타임 단축.

### 보스 캐릭터 (게임 시작 때 보스에게 고르게 하거나 랜덤)
기존 괴물을 격상시킨다. 각각 패턴 6개(분노 패턴 1개 포함).

| 보스 | 컨셉 | 패턴 예시 |
|---|---|---|
| **그림자 인형사** | 실·인형·막 | 실 휘두르기(가로 줄), 인형 군무(원형 돌진), 조종당하는 인형(유도), 막이 내린다(가림 벽 + 틈), 분노: 줄이 모두 끊긴다(전체 판 정리) |
| **거인** | 크고 느림, 큰 범위 | 발 구르기(충격파 고리), 돌 던지기(경고 후 착탄), 팔 휘두르기(부채꼴), 지진(바닥 구역), 분노: 거인의 분노(연쇄 충격파) |
| **줄 끊는 가위** | 빠르고 정밀 | 가위질(십자 빔), 실 끊기(유도탄), 분신 가위(좌우에서 교차), 오려내기(영역 삭제 후 복원), 분노: 마지막 가위(고속 십자) |

### 보스가 사람일 때
- 보스는 영웅의 **스펠 버튼 UI와 같은 패턴 버튼**을 쓴다 (쿨타임 표시). 패턴 구간에 눌러 발동, 영역 안에서 이동도 가능.
- 보스가 봇이면 규칙표대로 쿨타임이 되면 순서/랜덤으로 발동.
- **사람 보스에게 부담이 안 쏠리게**: 패턴은 자동 조준(가장 가까운 영웅/랜덤), 사람은 "어느 패턴을 언제"만 고른다.

## 3. 탐색 (비대칭)
- **영웅**: 지금과 같음. 얻은 재화는 보스전 강화에 쓰인다 (아래).
- **보스**: 큰 **보스 아바타**로 탐색에 참가. 자체 능력 3개 + 약한 추격 AI 괴물과 함께 영웅을 사냥한다.
  - 영웅을 **붙잡으면**: 그 영웅은 보스전 시작 시 하트 -1(최소 1), 재화 일부 강탈 → 보스의 **위협** 스택 +1.
  - **위협**이 쌓이면 보스전 패턴 쿨타임 단축 / 첫 턴 선공 / 체력 회복.
  - 영웅이 보스를 **따돌리거나 덫으로 막으면** 영웅의 공격 구간이 길어진다 (보스가 지친다).
- 보스 능력 예시 (보스 캐릭터마다 다름): **돌진**(짧은 가속), **포효**(영웅 위치 3초 노출), **소환**(약한 졸개 괴물 2마리).
- **포획·갈고리 (데바데 방식)**: 보스가 영웅을 붙잡으면 어깨에 메고 맵의 **갈고리(형틀)**까지 끌고 가 매단다. 매달린 영웅은 일정 시간이 지나면 **포로**가 되어 보스전 시작 때 하트 -1을 받고, 그 전에 **다른 영웅이 구출**하면 풀려난다 (구출하는 동안 소리가 나서 보스에게 들킴). 보스는 영웅을 갈고리에 매다는 동안 이동이 느려진다. → 영웅은 구출·교란·수리를 분담해야 하고, 보스는 갈고리 주변을 지킬지 다른 영웅을 쫓을지 고른다.

## 4. 재화의 사용 (영웅)
| 사용처 | 효과 |
|---|---|
| 공격력 | 평타·스펠 피해 +1단계 |
| 체력 | 최대 하트 +1 (최대 5) |
| 부활 | 쓰러진 영웅의 부활 하트 +1 |
| 직업 보너스 | 도감(기록자)·성흔(순교자) 등은 그대로 반영 |

→ 탐색을 못 하면 약하게 들어가고, 너무 못 하면 보스에게 막혀서 불리해진다.

## 5. 기존 직업과의 관계
- **듀얼 능력(평타·스펠 3개)** 그대로 쓴다 → 20종 전부 보스전 직업이 됨.
- **탐색 능력**은 탐색에서 그대로 쓴다.
- **특수 승리 직업**: 보스전에서는 특수 승리 조건 **비활성** (기술자 탈출, 점쟁이 예언, 순교자 성흔 승리).
  대신 기술자 = 탈출구가 열리면 보스전 아레나에 보호막 1회, 점쟁이 = 보스의 다음 패턴 예고를 영웅들에게 공개, 순교자 = 성흔으로 하트 회복 등 **보스전용 보너스**로 바꾼다.
- 일부 직업은 **팀 능력**이 생긴다: 수선공(영웅 부활), 기록자(보스 패턴 약점 표시, 개인전에서 보류했던 팀 공유), 엔터(응원 버프).

## 6. 구현 단계 (제안)
1. **N:1 탄막 엔진 + 봇 보스**: 영웅 여러 명이 한 아레나에서 움직이고 보스 패턴을 피하는 엔진, 보스 1종(그림자 인형사) + 패턴 6개. 로컬 1인 + 봇 영웅으로 검증.
2. **보스 3종 + 밸런스**: 거인·가위, 인원/직업 보정, 분노 패턴. 봇 시뮬레이션으로 영웅 승률 목표 45~55%.
3. **사람 보스 + 온라인**: 패턴 버튼 UI, 여러 영웅 입력 동기화.
4. **비대칭 탐색**: 보스 아바타, 위협 스택, 연동.
5. **마무리**: 부활/정산 UI, 도움말, 승리 연출.

## 7. 정해야 할 것 (제안안 포함)
| 질문 | 제안 |
|---|---|
| 영웅 인원 | 영웅 1~3명 (방 2~4인). 2인(보스1+영웅1)은 허용할지 |
| 보스 캐릭터 선택 | 보스 당첨자가 시작 때 고름 (3종) |
| 소집 한도 | 5소집 (영웅 승리가 어렵다면 6) |
| 영웅 승리 보상 | 협동 승리. MVP(가장 큰 피해) 표시 |
| 봇 영웅 | 사람이 적을 때 봇으로 채움 |

## 구현 현황 (1단계 완료)

- **엔진 (CORE)**: `makeBoss / bossHeal / stepBoss / bossHeroAI / runBossHeadless` — 영웅 N명 대 보스 1명, 패턴 구간 ↔ 공격 구간, 하트 3, 부활, 분노(체력 50%).
- **보스**: 그림자 인형사 (패턴 6: 실 휘두르기·인형 군무·조종당하는 인형·막이 내린다·실 가르기·분노 패턴 줄이 모두 끊긴다). 패턴 구간에 패턴 2개(분노 시 3개) 이하, 패턴마다 쿨타임.
- **체력**: 영웅 1/2/3명일 때 보스 체력 149 / 422 / 632 (봇 시뮬레이션으로 영웅 승률 약 40~80% 맞춤, 숙련도 0.6~0.9).
- **영웅 능력**: 직업 평타·스펠 3종 그대로. 패턴 구간에는 평타만 (피해 40%), 공격 구간에 스펠 + 평타 100%.
- **장면**: 모바일 드래그 이동, 스펠 버튼(공격 구간에만 활성), 소집 간 부활 연출. 진입: 타이틀 **보스전 체험** / `?demo=boss&n=3&jobs=a,b,c&bot=1`.
- **아직 없음**: 보스 2·3종(거인·가위), 사람 보스·온라인, 비대칭 탐색(포획·갈고리), 재화 강화, 정식 게임 흐름 연결.
